### S09 核心创新：持久化队友 + 异步通信

#### 子代理 vs 队友

| 特性 | S04 子代理 (run_subagent) | S09 队友 (TeammateManager) |
|------|--------------------------|---------------------------|
| 生命周期 | 单次任务 | 持久运行 |
| 通信方式 | 函数返回值 | JSONL 文件邮箱 |
| 消息传递 | 同步返回 | 异步写入 |
| 状态保持 | 无 | 有 (idle/working/shutdown) |
| 适用场景 | 一次性探索 | 长期协作 |

### JSONL 邮箱机制

#### 什么是 JSONL？

JSON Lines：每行一个 JSON 对象，适合追加写入

```
{"type": "message", "from": "lead", "content": "做这个任务", "timestamp": 1234567890.123}
{"type": "message", "from": "alice", "content": "完成了", "timestamp": 1234567891.456}
{"type": "broadcast", "from": "lead", "content": "所有人注意", "timestamp": 1234567892.789}
```

#### 邮箱目录结构

```
.team/
├── config.json      # {"team_name": "my-team", "members": [...]}
└── inbox/
    ├── lead.jsonl   # 领导收件箱
    ├── alice.jsonl  # alice 收件箱
    └── bob.jsonl    # bob 收件箱
```

#### MessageBus 实现

```python
class MessageBus:
    def __init__(self, inbox_dir: Path):
        self.dir = inbox_dir
        self.dir.mkdir(parents=True, exist_ok=True)

    def send(self, sender: str, to: str, content: str,
             msg_type: str = "message", extra: dict = None) -> str:
        msg = {
            "type": msg_type,
            "from": sender,
            "content": content,
            "timestamp": time.time(),
        }
        if extra:
            msg.update(extra)
        # 追加写入
        with open(self.dir / f"{to}.jsonl", "a") as f:
            f.write(json.dumps(msg) + "\n")
        return f"Sent {msg_type} to {to}"

    def read_inbox(self, name: str) -> list:
        path = self.dir / f"{name}.jsonl"
        if not path.exists():
            return []
        # 读取并清空
        msgs = [json.loads(l) for l in path.read_text().strip().splitlines() if l]
        path.write_text("")  # 清空文件
        return msgs
```

#### 为什么读后清空？

- 避免重复处理同一消息
- 每次 `read_inbox()` 是 "领取" 消息的过程
- 如果不清空，多个代理可能处理同一条消息

### TeammateManager

```python
class TeammateManager:
    def __init__(self, team_dir: Path):
        self.dir = team_dir
        self.config_path = self.dir / "config.json"
        self.config = self._load_config()
        self.threads = {}

    def spawn(self, name: str, role: str, prompt: str) -> str:
        # 创建或恢复队友线程
        member = self._find_member(name)
        if member:
            member["status"] = "working"
        else:
            member = {"name": name, "role": role, "status": "working"}
            self.config["members"].append(member)
        self._save_config()

        # 启动守护线程
        thread = threading.Thread(target=self._teammate_loop, args=(name, role, prompt), daemon=True)
        self.threads[name] = thread
        thread.start()
        return f"Spawned '{name}' (role: {role})"

    def _teammate_loop(self, name: str, role: str, prompt: str):
        # 队友的主循环：读取收件箱 -> 处理消息 -> LLM 调用
        sys_prompt = f"You are '{name}', role: {role}..."
        messages = [{"role": "user", "content": prompt}]
        tools = self._teammate_tools()

        while True:
            # 1. 读取收件箱
            inbox = BUS.read_inbox(name)
            for msg in inbox:
                messages.append({"role": "user", "content": json.dumps(msg)})

            # 2. LLM 调用
            response = client.messages.create(model=MODEL, system=sys_prompt, messages=messages, tools=tools)
            messages.append({"role": "assistant", "content": response.content})

            # 3. 工具执行
            if response.stop_reason != "tool_use":
                break
            results = []
            for block in response.content:
                if block.type == "tool_use":
                    output = self._exec(block.name, block.input)
                    results.append({"type": "tool_result", "tool_use_id": block.id, "content": output})
            messages.append({"role": "user", "content": results})
```

### 核心模式

```
领导：
  spawn_teammate(name, role, prompt)  # 启动队友
  send_message(to, content)           # 发消息
  read_inbox()                         # 收消息

队友（在线程中）：
  循环：
    read_inbox() -> 处理消息 -> LLM 调用 -> 工具执行
```

### 使用场景

1. **多角色协作**：一个"领导"代理协调多个专业队友
2. **异步任务处理**：队友在后台处理耗时任务
3. **长期运行代理**：跨越多个会话保持运行状态
4. **并行工作**：多个队友同时处理不同任务

### 关键流程说明

| 阶段 | 做了什么 | 为什么 |
|------|---------|--------|
| 1. 领导启动队友 | spawn_teammate() 创建配置和线程 | 领导告诉 LLM 要做什么 |
| 2. 队友空闲等待 | read_inbox() 返回空，线程睡眠 5 秒 | 不占用 CPU，等待消息 |
| 3. 领导发消息 | send_message() 写入队友的 JSONL 文件 | 异步通信，不阻塞 |
| 4. 队友被唤醒 | read_inbox() 读到消息，状态改为 working | 消息驱动的工作模式 |
| 5. 队友执行任务 | 调用 LLM，执行工具，写入结果 | 队友独立工作 |
| 6. 队友回报结果 | send_message() 写入领导的 JSONL 文件 | 异步回报，不等待 |

### 领导与队友的通信模式

```
领导 (主线程)                    队友 (独立线程)
      │                              │
      │  spawn_teammate() ───────────>│  创建线程
      │                              │
      │  send_message() ───────────>│  写 alice.jsonl
      │     (异步，不等待)           │
      │                              │  read_inbox() ← 读 alice.jsonl
      │                              │  (有消息则处理，无消息则等待)
      │                              │
      │  <────── send_message() ─────│  写 lead.jsonl
      │     read_inbox()            │  (异步，不等待)
      │                              │
```
